# palps-prototype

نماذج الواجهة الجديدة لموقع شبكة الصحافة الفلسطينية (palps.taktek.co): ثلاث عينات، A «الريشة» وB «الخريطة» وC «الحبر».

- `index.html` is the chooser page.
- `a/`, `b/`, `c/` each have `home.html` (the homepage) and `index.html` (the identity book).
- `BRIEF.md` is the brief all three were built from. `data/content.json` is the real content they use.

The chosen direction will be wired into devlo-cms (theme `palps`).
